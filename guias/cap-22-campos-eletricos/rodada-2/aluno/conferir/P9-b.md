# Conferência de P9-b

Campo: (b) ângulo com +x = [°]

Valor esperado: 180 °  (ângulo: vale qualquer equivalente mod 360°, ±1,5°)

Erros comuns que a página reconhece (valor → mensagem):
- 0 → Sentido invertido. O +q (à direita) empurra P para longe dele (para a esquerda); o −q (à esquerda) puxa P para ele (também para a esquerda).
- 90 → As componentes y se cancelam (sinais opostos). Sobra só x.
- -90 → As componentes y se cancelam (sinais opostos). Sobra só x.
