# Conferência de pre6

- a) errada — Se F fosse maior que W, sobraria força para cima e a bolinha subiria.
- b) errada — Com as duas para baixo, a soma não pode ser zero.
- c) **CERTA** — Isso: parada → ΣF = 0 → forças de mesmo módulo e sentidos opostos.
- d) errada — Não há motivo para o fator 2: o equilíbrio pede soma zero.

Mini-revisão (aparece na página para quem erra): Mini-revisão. 2ª lei de Newton: \(\sum\vec F = m\vec a\). Parado (ou velocidade constante) → \(\vec a = 0\) → \(\sum\vec F = 0\). Com duas forças só, elas têm o mesmo módulo e sentidos opostos.
