# Conferência de pre4

- a) errada — 53° é o que a calculadora dá para atan(4/3), mas esse vetor tem x e y negativos: está no 3º quadrante.
- b) errada — −53° fica no 4º quadrante (x positivo).
- c) errada — 127° fica no 2º quadrante (y positivo).
- d) **CERTA** — Isso: 3º quadrante, 180° + 53° = 233°, que é o mesmo que −127°.

Mini-revisão (aparece na página para quem erra): Mini-revisão. A calculadora devolve atan(y/x) só entre −90° e +90°, e (−3, −4) dá a mesma razão que (3, 4). Faça assim: (1) ache o ângulo de referência, atan(|y|/|x|) = 53°; (2) desenhe o vetor para ver o quadrante; (3) ajuste: 3º quadrante → 180° + 53° = 233°.
