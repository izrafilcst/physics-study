# PA3, nível 4: Resolução comentada


#### Resolução comentada

Entender Anel de raio R, carga q; P no eixo a uma distância z. Mostrar a fórmula.

Modelar Campo de carga pontual para cada pedaço dq e superposição.

Resolver em símbolos \(dE = \dfrac{k\,dq}{r^2}\), \(r = \sqrt{z^2+R^2}\). Componente ao longo do eixo: \(dE_z = dE\cos\theta = \dfrac{k\,dq}{r^2}\dfrac zr\). A componente perpendicular de um dq se cancela com a do dq diametralmente oposto. Como z e r são iguais para todos os pedaços: \(E = \dfrac{kz}{r^3}\displaystyle\int dq = \frac{kqz}{(z^2+R^2)^{3/2}}\).

▸ [recolhido, abre ao clicar] Por que não basta escrever "E = kq/r²"?
   Porque os dE dos pedaços não são paralelos: cada um aponta numa direção diferente. Somar módulos dá kq/r², que é maior que o certo. A questão diz "mostre": a nota está em mostrar o cancelamento e a projeção.

Calcular (valor-teste) \(E = \dfrac{(8{,}99\times10^9)(5{,}0\times10^{-9})(0{,}040)}{(0{,}050)^3} = 1{,}44\times10^4\) N/C.

Verificar z = 0 → E = 0 (pares opostos se anulam no centro). z ≫ R → E ≈ kq/z² (carga pontual). E se você quiser o ponto de campo máximo? dE/dz = 0 dá z = R/√2.

Na folha da prova

Desenho: anel, P, dq e dE com componentes. \(dE = k\,dq/r^2\), \(r = \sqrt{z^2+R^2}\).

Simetria: componentes ⊥ ao eixo se cancelam aos pares; \(dE_z = dE\cdot z/r\).

\(E = \frac{kz}{r^3}\int dq = \frac{1}{4\pi\varepsilon_0}\frac{qz}{(z^2+R^2)^{3/2}}\). Checagem: z = 0 → 0; z ≫ R → kq/z².
