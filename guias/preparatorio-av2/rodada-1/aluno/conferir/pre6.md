# Conferência de pre6

- a) errada — A velocidade tem módulo constante, mas muda de direção. Isso exige força.
- b) errada — Força na direção da velocidade mudaria o módulo dela. No MCU o módulo não muda.
- c) **CERTA** — Isso. No círculo dentro de um campo B, essa força é a magnética: |q|vB = mv²/r.
- d) errada — Unidade errada: mv/r dá kg/s, não newton.

Mini-revisão (aparece na página para quem erra): Mini-revisão. MCU: aceleração centrípeta \(v^2/r\), para o centro. Então \(F_{res} = mv^2/r\). No Degrau 5, a força magnética faz esse papel.
