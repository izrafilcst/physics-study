# P30-27, nível 4: Resolução comentada


#### Resolução comentada

Entender a = 0,020 m; B = 4,0t²y (⊙); t = 2,5 s.

Modelar Faraday com fluxo não uniforme (B muda com y e com t).

Resolver em símbolos \(\Phi = 4{,}0\,t^2a\displaystyle\int_0^a y\,dy = 2{,}0\,t^2a^3\) → \(|\mathcal E| = \dfrac{d\Phi}{dt} = 4{,}0\,t\,a^3\).

Calcular \(|\mathcal E| = 4{,}0(2{,}5)(0{,}020)^3 = 8{,}0\times10^{-5}\) V = 80 μV.

Verificar A constante 4,0 tem unidade T/(s²·m); vezes s·m³ dá T·m²/s = V. Sentido: Φ ⊙ crescendo → induzido ⊗ → horário. E se a espira estivesse abaixo do eixo x (y negativo)? B mudaria de sinal ali.
