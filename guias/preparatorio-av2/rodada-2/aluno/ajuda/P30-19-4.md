# P30-19, nível 4: Resolução comentada


#### Resolução comentada

Entender N = 100; A = 0,500 × 0,300 = 0,150 m²; B = 3,50 T; 1000 rpm.

Modelar Faraday: o ângulo entre B e a normal muda: θ = ωt.

Resolver em símbolos \(\Phi = BA\cos\omega t\) → \(\mathcal E = -N\,d\Phi/dt = NBA\omega\,\text{sen}\,\omega t\) → \(\mathcal E_{máx} = NBA\omega\).

Calcular ω = 104,7 rad/s; \(\mathcal E_{máx} = (100)(3{,}50)(0{,}150)(104{,}7) = 5{,}50\times10^3\) V.

Verificar Unidade: T·m²/s = V. 5,5 kV é alto, mas B = 3,5 T é um campo fortíssimo. E se a rotação dobrar? A fem máxima dobra (e a frequência também).
