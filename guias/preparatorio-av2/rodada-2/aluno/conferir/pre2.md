# Conferência de pre2

- a) **CERTA** — Isso: a primitiva é −1/x; −1/(a+L) − (−1/a) = 1/a − 1/(a+L). É a conta da barra no eixo.
- b) errada — Esqueceu o sinal de menos da primitiva (−1/x). Isso dá um número negativo para uma integral de algo positivo.
- c) errada — ln aparece na integral de 1/x, não de 1/x².
- d) errada — Isso seria tratar 1/x² como constante (valor na ponta) e multiplicar por L.

Mini-revisão (aparece na página para quem erra): Mini-revisão. \(\int x^n dx = x^{n+1}/(n+1)\) para n ≠ −1. Com n = −2: \(x^{-1}/(-1) = -1/x\). Com n = −1 o caso é especial: \(\int dx/x = \ln x\).
