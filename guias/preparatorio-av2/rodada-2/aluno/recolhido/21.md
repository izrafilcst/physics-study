# Ver correção da Questão 4 (só depois de terminar)

Semicircunferência: \(B = \frac{\mu_0 i\varphi}{4\pi R}\) com φ = π → \(\frac{\mu_0 i}{4R}\). Cada trecho reto semi-infinito (Biot-Savart, como no Degrau 6): \(B = \frac{\mu_0 i}{4\pi}\int_0^\infty\frac{R\,dx}{(x^2+R^2)^{3/2}} = \frac{\mu_0 i}{4\pi R}\) (troca x = R tg θ, θ de 0 a 90°). Checagem: é a metade do fio infinito. Mão direita: as três partes dão B em C entrando no papel (⊗). Somam. \(B = \frac{\mu_0 i}{4R} + 2\cdot\frac{\mu_0 i}{4\pi R} = 5{,}03\cdot10^{-5} + 3{,}20\cdot10^{-5} = 8{,}2\cdot10^{-5}\) T, para dentro do papel.
